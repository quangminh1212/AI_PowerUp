# Advanced-QA-and-RAG-Series

[Farzad-R/Advanced-QA-and-RAG-Series](https://Farzad-R/Advanced-QA-and-RAG-Series)

Advanced LLM-based chatbots for Retrieval Augmented Generation (RAG) and Q&A with vector databases, graph databases, SQLite, CSV, and XLSX. The repository demonstrates using Azure OpenAI and OpenAI APIs across its projects, with accompanying YouTube guides.

## Projects

- RAG Evolution — eight state-of-the-art techniques
- LangGraph agentic customer support
- AgentGraph intelligent Q&A and RAG system
- Q&A and RAG with SQL and tabular data
- Knowledge-graph Q&A and RAG with tabular data
