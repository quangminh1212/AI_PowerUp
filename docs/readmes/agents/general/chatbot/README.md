## Description

**ChatBot** is a modern, responsive AI-powered chatbot built using **HTML**, **CSS**, and **JavaScript**, integrated with the **Google Gemini API**. This project demonstrates how powerful AI models can be connected directly to frontend applications to create intelligent, real-time conversational experiences.

The chatbot enables users to ask questions and receive meaningful AI-generated responses using Google Gemini. The main focus of this project is **simplicity**, **clean UI**, and **smooth API integration** without relying on heavy backend frameworks.

## ✨ Features

- 🧠 **AI-powered** conversational chatbot using Google Gemini API
- ⚡ **Real-time** response generation
- 🎨 Clean and **responsive** chat interface
- 🌐 Fully **frontend-based** implementation
- 🔌 Easy API integration and configuration
- 🪶 Lightweight, fast, and beginner-friendly
- 🌍 Works directly in the browser

## 🔄 How It Works

1. 💬 The user enters a message in the chat input box
2. 📤 JavaScript sends the prompt to the Google Gemini API
3. 🤖 Gemini processes the prompt using its AI model
4. 📥 The API sends back an AI-generated response
5. ✅ The chatbot displays the response instantly in the UI

## 🚀 Setup & Usage

### 1. Clone the repository
```bash
git clone https://github.com/vivekverma807/ChatBot.git
cd ChatBot
```

### 2. Configure Google Gemini API
- Open `config.js`
- Add your Google Gemini API key:
```javascript
const API_KEY = 'YOUR_GEMINI_API_KEY_HERE';
```

### 3. Run the chatbot
- Open `index.html` in your browser
- Start chatting with the AI!

## 🔑 Google Gemini API

This project uses **Google Gemini** for AI-powered responses.

**Requirements:**
- ✅ Valid Google Gemini API key
- ✅ Active internet connection

🔗 API keys can be generated from [Google AI Studio](https://makersuite.google.com/app/apikey).
