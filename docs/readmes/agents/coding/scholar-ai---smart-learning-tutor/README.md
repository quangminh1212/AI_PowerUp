# keshav443/Scholar-AI---Smart-Learning-Tutor

AI Study Tutor Assistant is a smart, AI-powered learning platform designed for college and higher education students, especially in technical fields. It offers personalized tutoring, subject-wise explanations, AI-generated notes, quizzes, and a built-in coding assistant inspired by tools like Cursor IDE.

# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/dfb30a93-713a-4467-9183-efed33ff3f73

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
