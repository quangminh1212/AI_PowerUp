# Awesome Agentic Workflow Repository

A curated collection of GitHub repositories focused on agentic workflows, autonomous agents, multi-agent systems, and AI workflow automation. This repository serves as a comprehensive resource hub containing summarized documentation from projects related to intelligent agent frameworks and automated workflow orchestration.

## 🗂️ Repository Structure

The repository is organized into **8 main categories**, each containing summarized README files from relevant GitHub projects:

### 📁 Category Folders

- **Autonomous** - Self-governing agent systems that operate independently
- **Human-in-the-Loop** - Systems that integrate human oversight and intervention
- **Hybrid** - Combined approaches mixing autonomous and human-controlled elements
- **Multi-Agent** - Systems involving coordination between multiple agents
- **Orchestrated** - Centrally managed and coordinated workflow systems
- **Planning_Reasoning** - Agents focused on strategic planning and logical reasoning
- **Reflection_Adaptation** - Self-improving systems with learning capabilities
- **Single Agent** - Individual agent implementations and frameworks
- **Tool Integration** - Agent systems that leverage external tools and APIs


## 📋 Project Metadata Format

Each summarized project includes comprehensive metadata:

- **Repository Information**: Name, URL, star count, primary language
- **Categorization**: Primary and relevant categories with explanations
- **Technical Details**: Description, methodology, approach
- **Academic Sources**: Research papers, arXiv links, citations
- **Usage Instructions**: Installation, setup, and practical examples
