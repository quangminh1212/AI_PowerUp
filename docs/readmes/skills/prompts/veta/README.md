# Jimmy0743/Veta

基于大模型构建的在线 AI 问诊的多智能体宠物医生 Agent。系统面向多种常见宠物疾病，整合并构建高质量的知识库，能够通过多轮对话实现智能化问诊。项目结合 Prompt Engineering 与 LangGraph 框架，支持用户与智能体之间的自然交互，最终为用户提供个性化的药物与治疗方案推荐。

# Vet-Agent
基于大模型构建的在线 AI 问诊的多智能体宠物医生 Agent。系统面向多种常见宠物疾病，整合并构建高质量的知识库，能够通过多轮对话实现智能化问诊。项目结合 Prompt Engineering 与 LangGraph 框架，支持用户与智能体之间的自然交互，最终为用户提供个性化的药物与治疗方案推荐。
