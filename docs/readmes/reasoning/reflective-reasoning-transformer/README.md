# Reflective Reasoning Transformer (R2T) Prototype

This project is a prototype for the **R2T**, a model trained with **Causally-Grounded Dynamic Reasoning Pretraining (CG-DRP)**.
The goal is to create a model with provably higher reasoning faithfulness by training it on causal reasoning graphs.
