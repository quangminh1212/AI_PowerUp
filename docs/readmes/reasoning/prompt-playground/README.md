# prompt-playground
A Python + Streamlit tool to practice modern prompt engineering techniques including Chain-of-Thought, Tree-of-Thought, ReAct, Prompt Chaining, Prompt Injection Defense and others. Designed as a hands-on playground for learning how different prompt styles influence AI reasoning.
