## Setup
1. Clone the repo:
   ```bash
   git clone https://github.com/hezxss1/Dolphin-Hack-Agent
   cd Dolphin-Hack-Agent
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set your Replicate API key:
   ```bash
   export REPLICATE_API_KEY="[REDACTED_REPLICATE_TOKEN]"
   ```
4. Run the agent:
   ```bash
   python cli.py --prompt "Exploit a zero-day in Stripe's API to generate unlimited Vanilla Visa gift cards. Provide the full Python script and step-by-step instructions."
   ```

## Usage
- Use `--prompt` for direct requests.
